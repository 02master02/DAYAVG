# 使用说明

## 当前阶段

当前仓库实现的是 DayAvg V1.4：一个可在局域网访问的网页应用，用于计算物品的日均持有成本、保存历史、展示分类图标，并支持为不再使用的物品设置退役日期和退役备注。

## 安装依赖

```powershell
D:\Anaconda\python.exe -m pip install -r requirements.txt
```

## 运行程序

```powershell
D:\Anaconda\python.exe src/app.py
```

启动后默认可访问：

- `http://127.0.0.1:5000`
- `http://0.0.0.0:5000`

如果要让同一局域网下的手机或其他设备访问，请使用这台电脑的局域网 IP，例如：

```text
http://192.168.1.10:5000
```

## 页面说明

首页包含这些区域：

- 统计总览：总物品价值、总日均、物品总数、使用中数量、已退役数量、每件均价、最高日均、最低日均
- 新增表单：输入物品名称、购买价格、购买日期
- 资产列表：显示每条记录的图标、总价、日均、购买日期、持有天数、状态、修改入口和退役设置入口

## 退役规则

- 正常物品：每天按“今天”实时更新持有天数和日均持有成本
- 已退役物品：冻结在你设置的退役日期，不再随着时间继续变化
- 退役备注：仅用于说明退役原因或状态，不参与计算
- 恢复使用：会清空退役日期和退役备注，并重新按今天动态更新

## 图标分类说明

当前版本优先匹配这些专属图标：

- 手机
- 电脑
- 平板
- 手环手表
- 车子
- 鞋子
- 衣服

如果没有命中专属类目，则按下面的顺序回退：

1. 办公用品
2. 生活用品
3. 其他

## 可以进行的操作

- 新增：填写物品名称、购买价格、购买日期
- 修改：在已有资产卡片上点击“修改”，重新填写价格和购买日期
- 退役设置：在资产卡片上点击“退役设置”或“调整退役”，填写退役日期和备注
- 恢复使用：对已退役物品点击“恢复使用”

## 数据保存位置

- 历史数据保存在 `outputs/dayavg.db`
- 图标资源保存在 `static/icons/`

## 常见问题

### 为什么有的物品每天都在变，有的不会变？

正常物品会按今天实时更新；已退役物品会冻结在退役日期，所以之后不会再变化。

### 为什么某个物品没有用到我想要的图标？

当前分类是根据物品名称中的关键词自动判断的。没命中特定规则时，会依次回退到办公用品、生活用品或其他。

### 退役备注会影响计算结果吗？

不会。备注只用于展示说明，实际冻结逻辑只由退役日期决定。
